Everything before this window, in one card: the simulated network that approves, declines, loses
replies and goes down on demand; the `/v1` API with projects, scoped keys, payments, checkout
sessions, webhook endpoints and the error envelope; the immutable double-entry journal behind every
balance; strict idempotency with `uncertain` as a first-class state; signed webhook delivery,
at-least-once and honest about it; the hosted checkout with no card field; the operator CLI and the
TypeScript SDK; and dataset epochs that archive rather than delete. The pages on this site cover
each in depth — start with the [quick start](/quick-start/).
